# Портфолио Анны Ивановской

Статичный сайт без сборки, публикуется через GitHub Pages из ветки `main` (корень): https://ivanovskaiaaanna.github.io/cv/

- `js/content.js` — все тексты RU/EN. Правки текста — только здесь, дословно как пришлёт Анна.
  В русской версии — только кириллица (исключения: SQL, почта, ник в Телеграме; «В2+» набрано кириллической «В»). В английской — ни одного русского слова.
- `js/app.js` — рендер главной и кейсов (кейс = полноэкранная панель, адрес `#slug`), RU/EN, копирование email.
- `css/style.css` — стили, mobile-first. Палитра: бумага #EDEDE8, текст #1B1C17, вторичный #6A6B62, единственный акцент оливковый #7A8B12, мягкий #DDE3B8. Шрифты: Unbounded / Manrope / PT Mono / Caveat (Caveat — не больше 3–4 пометок на страницу). Без второго акцентного цвета, градиентов, эмодзи.
- `img/` — готовые WebP. По умолчанию ч/б; в цвете — только главный портрет `portrait-color` и материалы Вольтны (`voltna-*`); обложка Вольтны — логотип. Новые фото: положить исходники в `photos/` (не коммитится) и запустить `python3 tools/prepare_photos.py`.
- `docs/` — файлы для скачивания (презентация Вольтны).

Перед пушем проверять на ширине 390px (без горизонтального скролла) и на десктопе.
